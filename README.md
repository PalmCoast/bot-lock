# Bot Lock

Agent security from AgentHive Inc.

- **Bot Lock MCP server** (free, MIT): local stdio server with an Ed25519 agent identity, an AES-256-GCM vault, a signed hash-chained audit log, deny-by-default scope checks and a kill switch. See [`mcp/`](mcp/README.md).
- **Bot Lock Check** (free): browser self-assessment at https://bot-lock.netlify.app/check
- **Field Kit ($49) / Pro ($149)**, one-time: the Bot Lock Playbook and policy YAML templates. Pro currently includes the same material as the Field Kit.
